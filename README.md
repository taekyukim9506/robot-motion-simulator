# Robot Motion Simulator

A web application for simulating a robotic arm and a mobile robot.

This project is part of the IU course Project Java and Web Development
(DLBCSPJWD01).

## Main features

- User registration and login
- Robotic arm movement using roll, pitch, yaw and speed
- Mobile robot movement using X and Y coordinates
- Motion sequences, separate motion histories and replay
- Responsive interface for desktop and smaller screens

## Technologies

- Java and Spring Boot
- Maven
- H2 database
- HTML, CSS and JavaScript
- Three.js for the robotic arm visualization

## Development background

I created an initial version during my gap semester. This repository
documents a staged rebuild of that version, followed by testing,
fixes and improvements for the development phase.
